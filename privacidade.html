Privacidade e RGPD

Como tratamos os teus dados

Última atualização: agosto de 2026

Esta página resume, de forma direta, o que acontece com os teus dados quando usas o hyybu. — sem letras miudinhas. Se quiseres o texto legal completo, tens a Política de Privacidade formal ao fundo desta página.

As tuas apólices ficam só no teu telemóvel
Marca, matrícula, coberturas, vencimentos — tudo o que preenches ou carregas fica guardado localmente, no armazenamento do teu próprio dispositivo. Não existe uma base de dados central com a tua informação.
Não vendemos nem partilhamos dados
Não temos servidores com a tua informação, por isso não há nada para vender ou partilhar com seguradoras, anunciantes, ou qualquer terceiro para fins comerciais.
A leitura da apólice é a única exceção
Quando carregas uma foto ou PDF, o documento é enviado temporariamente para ser lido e devolver os dados extraídos. O ficheiro não fica guardado depois de lido. Se preferires, podes sempre preencher tudo manualmente e evitar este passo.
Podes apagar tudo quando quiseres
Nas definições da app podes eliminar todos os dados guardados no dispositivo, sem teres de pedir a ninguém.

O que guardamos nos nossos servidores

A resposta curta: quase nada. As duas únicas exceções, e o que cada uma implica:

  • Lista de espera: se te inscreveres para acesso antecipado, guardamos o teu email para te avisar do lançamento — nada mais.
  • Lembretes por inatividade (opcional): se ativares esta opção na app, guardamos o teu email e a data da tua última utilização, só para saber quando te lembrar. Nunca guardamos os dados das tuas apólices nesse processo.
Em nenhum dos dois casos recebemos ou guardamos matrícula, garantias, número de apólice, ou qualquer informação sobre os teus seguros. Isso continua a viver só no teu dispositivo.

Os teus direitos ao abrigo do RGPD

Como qualquer titular de dados na União Europeia, tens direito a:

  • Acesso — saber que dados temos sobre ti (no caso do hyybu, tipicamente só o teu email, se te inscreveste).
  • Retificação — corrigir dados incorretos.
  • Apagamento — pedir que removamos o teu email das nossas listas a qualquer momento.
  • Portabilidade — receber os teus dados num formato estruturado.
  • Oposição — opores-te ao tratamento dos teus dados.
  • Retirada do consentimento — a qualquer momento, sem afetar o tratamento já feito até essa data.

Base legal e responsável pelo tratamento

O tratamento dos dados que recolhemos (email para lista de espera ou lembretes) baseia-se no teu consentimento explícito, nos termos do Art. 6.º, n.º 1, al. a) do Regulamento (UE) 2016/679 (RGPD). O responsável pelo tratamento é o hyybu., contactável através de hyybu@hyybu.pt.

Queres exercer algum destes direitos?

Escreve para hyybu@hyybu.pt — respondemos diretamente, sem formulários nem burocracia. Se não ficares satisfeito com a resposta, podes sempre apresentar reclamação junto da CNPD.
